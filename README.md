# Body Repair AI

Локальная лаборатория для ретуши фотографий кузовных деталей по отдельной маске. Проект строится так, чтобы изображения оставались на компьютере, а интерфейсы и модели можно было заменять независимо.

## Текущий статус

Первый каркас содержит:

- доменную модель задания;
- локальное файловое хранилище для будущего датасета;
- подготовку бинарной и мягкой масок;
- заменяемый inference-backend;
- конфигурацию через `.env`;
- тесты базовой логики.

Для быстрой проверки без модели доступен `mock`-backend. Рабочий локальный
baseline использует ComfyUI и SDXL Base; фотографии не отправляются во внешние сервисы.

## Быстрый старт

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
pytest
```

Запуск локального интерфейса:

```powershell
.\scripts\start.ps1
```

Затем открыть `http://127.0.0.1:8000`. Маска рисуется прямо поверх фотографии:

- голубая разметка в редакторе сохраняется белым и обозначает кузовную деталь;
- красный обозначает вмятины;
- жёлтый обозначает грязь;
- пурпурный обозначает царапины;
- чёрный фон и ластик обозначают защищённую область.

Белая область детали сохраняется как контекстная `part mask`, но сама по себе
не разрешает модели перерисовывать всю деталь. Итоговая edit-маска строится
только из красных, жёлтых и пурпурных штрихов. В режиме `mock` результат равен
оригиналу — этот режим нужен для проверки сохранения файлов, масок, метаданных
и пользовательского сценария.

### Подключение ComfyUI

Для NVIDIA можно установить изолированную portable-сборку и официальный SDXL
checkpoint одной командой (потребуется около 12–15 ГБ):

```powershell
.\scripts\setup-comfyui.ps1
```

После установки весь стек можно запустить одной командой:

```powershell
.\scripts\start-local.ps1
```

Если на порту `8000` остался старый `mock`-сервер, сначала остановите его
сочетанием `Ctrl+C`.

Скрипт поднимает ComfyUI в фоне, ждёт его готовности и запускает веб-приложение.
Логи ComfyUI сохраняются в `.runtime/logs`. Для раздельной отладки можно в
первом терминале запустить ComfyUI:

```powershell
.\scripts\start-comfyui.ps1
```

После появления адреса `http://127.0.0.1:8188` во втором терминале запустить
приложение:

```powershell
.\scripts\start.ps1
```

Готовый API workflow находится в `workflows/sdxl_inpaint_api.json`. Он меняет
только маскированную область, использует умеренный denoise `0.38` и рассчитан
на первый сравнительный baseline, а не на финальное качество.

Приложение загружает в ComfyUI только crop с контекстом и его маску, ждёт
результат, возвращает crop к исходному размеру и принудительно сохраняет
оригинальные пиксели вне мягкой маски.

## Правила хранения данных

- `data/raw` — неизменяемые оригиналы;
- `data/annotations` — маски;
- `data/candidates` — результаты отдельных запусков;
- `data/accepted` — принятые результаты;
- `data/rejected` — отклонённые результаты;
- `data/exports` — подготовленные версии датасета.

Каталоги `data`, `models` и файлы весов исключены из Git.

## Работа с Git

Основная ветка — `main`. Для экспериментов создавайте отдельные ветки:

```powershell
git switch -c experiment/sdxl-inpaint
```

Workflow ComfyUI и код адаптера коммитятся, веса моделей и фотографии — нет.
