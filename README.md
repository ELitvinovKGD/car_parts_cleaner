# Body Repair AI

Локальная лаборатория для ретуши фотографий кузовных деталей по отдельной маске. Проект строится так, чтобы изображения оставались на компьютере, а интерфейсы и модели можно было заменять независимо.

## Текущий статус

Первый каркас содержит:

- доменную модель задания;
- локальное файловое хранилище для будущего датасета;
- подготовку бинарной и мягкой масок;
- заменяемый inference-backend;
- конфигурацию через `.env`;
- тесты базовой логики.

По умолчанию используется `mock`-backend: он позволяет проверить весь конвейер без скачивания моделей. ComfyUI будет подключаться отдельным адаптером.

## Быстрый старт

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
pytest
```

Запуск локального интерфейса:

```powershell
.\scripts\start.ps1
```

Затем открыть `http://127.0.0.1:8000`. Сейчас интерфейс работает с отдельной
PNG-маской. Белая область маски разрешает редактирование, чёрная защищена.
В режиме `mock` результат равен оригиналу — этот режим нужен для проверки
сохранения файлов, масок, метаданных и пользовательского сценария.

## Правила хранения данных

- `data/raw` — неизменяемые оригиналы;
- `data/annotations` — маски;
- `data/candidates` — результаты отдельных запусков;
- `data/accepted` — принятые результаты;
- `data/rejected` — отклонённые результаты;
- `data/exports` — подготовленные версии датасета.

Каталоги `data`, `models` и файлы весов исключены из Git.

## Работа с Git

Основная ветка — `main`. Для экспериментов создавайте отдельные ветки:

```powershell
git switch -c experiment/sdxl-inpaint
```

Workflow ComfyUI и код адаптера коммитятся, веса моделей и фотографии — нет.
