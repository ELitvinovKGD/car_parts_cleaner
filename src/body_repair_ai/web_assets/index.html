Эксперимент: заменить деталь по хорошему фото-донору

Сначала выделите слой «Деталь» на исходной фотографии. Затем загрузите хорошую фотографию такой же детали и выделите её через SAM 2.

Нажмите SAM 2 и протяните рамку вокруг детали-донора. Первый вариант выравнивает детали по их границам; фон исходной фотографии не меняется.
